關於資料集：版本沿革

資料集的欄位與編碼會隨版本演進；每筆資料屬於哪個版本，寫在下載頁檔案庫的「資料集版本」欄位。目前最新版本為0.3。

0.3 版

發行 2023/08/31適用期間：2023/08 起（過渡版本，僅用於季度、年度資料）

消除重複資料集欄位調整：「最大刊登者編碼」改「常見刊登者編碼」、「約略地點範圍」拆為「常見約略地點_x/_y」、新增「物件最後更新時間」。

0.2 版

發行 2018/08/31適用期間：2018/08 – 2023/08

新增「約略地點」、「約略地點範圍」。

0.1 版

發行 2018/07/31適用期間：2018/07 – 2023/08（與 0.2 相容）

新增「資料集版本」概念與 JSON 格式；新增消除重複、去除非住宅物件的資料集與「刊登者編碼」；二選一欄位由 0/1 改為 T/F。

0.0 版

發行 2018/06/06適用期間：2018/06 – 2018/12

初版：定義共同資料欄位、編碼表，以 CSV 格式釋出未過濾的原始資料。
